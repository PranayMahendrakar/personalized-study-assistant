# 📚 Personalized Study Assistant

AI-powered study tool that creates flashcards, quizzes, and personalized study plans from lecture notes and textbooks.

**Author:** Pranay M

## Features
| Module | Description |
|--------|-------------|
| Flashcard Generator | Create flashcards and cloze deletions |
| Quiz Generator | Generate quizzes and practice tests |
| Note Analyzer | Extract key concepts, identify gaps |
| Study Planner | Create personalized study schedules |
| Concept Explainer | Explain concepts with analogies |
| Progress Tracker | Track learning progress |
| Summary Generator | Create study summaries and cheat sheets |
| Practice Problem Generator | Generate practice problems with solutions |
| Vocabulary Builder | Build subject-specific vocabulary |
| Review Scheduler | Spaced repetition scheduling |

## Usage
```bash
pip install -r requirements.txt && python main.py
```
